# 🚗 AutoZone – Auto Parts & Accessories

AutoZone is a responsive **automotive parts and accessories website** created as a student web development project. The website provides a simple interface for finding vehicle parts, checking vehicle compatibility, browsing products, managing a shopping cart, viewing deals, and reading installation guides.

## 📌 Project Overview

**Project Name:** AutoZone
**Project Type:** Automotive E-Commerce Website
**Domain:** Web Development / E-Commerce
**Project Level:** Student Project

The main purpose of this project is to create an easy-to-use online platform where users can explore automotive products and find parts according to their vehicle details.

## ✨ Features

### 🏠 Home Page

* AutoZone branding and navigation
* Search bar for parts
* Account section
* Store locator
* Shopping cart
* Promotional shipping information

### 🔎 Search Parts

Users can search for automotive parts using:

* Part name
* Brand
* Part number

### 🚘 Vehicle Part Finder

Users can enter vehicle information such as:

* Year
* Make
* Model
* Engine
* Trim

The project includes vehicle options from brands such as Toyota, Honda, Ford, Chevrolet, BMW, Mercedes-Benz, Hyundai, Kia, Volkswagen, and Nissan.

### 🛠️ Shop Parts

The website provides a product-shopping section where users can browse automotive parts and add products to the cart.

### ✅ Vehicle Compatibility

A dedicated vehicle compatibility section is included to help users check whether a selected part is suitable for their vehicle.

### 🛒 Shopping Cart

The cart section allows users to:

* View selected products
* Select product quantity
* Review cart items
* View the order total
* Continue shopping

The project includes quantity selection and an **Add to Cart** workflow.

### 💰 Deals

A dedicated deals section is included for displaying special offers and automotive product deals.

### 📚 Installation Guides

The website includes installation guides to help users understand basic vehicle maintenance and part installation procedures.

### 👤 Account Section

An account section is included for the website's user interface.

### 📍 Store Locator

The navigation includes a Store Locator option for helping users find a physical store.

### 📱 Responsive Design

The website uses responsive CSS so that the layout adapts to different screen sizes, including mobile devices.

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout and responsive design
* **HTML Forms** – Search, vehicle selection and product interactions
* **Responsive CSS** – Mobile and desktop layouts

The project is contained in a single HTML file with CSS included inside the document.

## 🚀 How to Run the Project

### Method 1 – Open Directly

1. Download or clone the repository.
2. Open the `autozone.html` file.
3. Double-click the file.
4. The website will open in your browser.

### Method 2 – Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `autozone.html`.
3. Right-click the file.
4. Select **Open with Live Server** if Live Server is installed.
5. The website will open in your browser.

This is a **frontend/student project** created for learning and demonstration purposes.

The vehicle compatibility section is currently a demo interface; the source itself states that the selected choices do not change the static example result.

It does not represent a complete production automotive e-commerce system with a connected backend, database, live inventory, or real payment processing.
